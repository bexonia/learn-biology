# Bexonia Learn Biology (`learn-biology`) — Architectural Roadmap

This directory contains the step-by-step architectural and feature roadmap for **`learn-biology`** (`https://learn.bexonia.com`). Each document outlines a specific phase, its **Whole → Tiniest** biological drill-down design (from macro systems and whole cells/organisms down to organelles, PDB nanomachines, biomolecules, monomers, and `0.1 nm` atoms), its bilingual 3-persona Guided Tour with strict analogy restraint (`AGENTS.md` Rule 8), verification gates, and implementation steps.
