# Bexonia Learn Biology (`learn-biology`) — Architectural Roadmap

This directory contains the step-by-step architectural and feature roadmap for **`learn-biology`** (`https://learn.bexonia.com`). Each document outlines a specific phase, its design and technical context, verification gates, and implementation steps.

## Completed & Planned Milestones Checklist

- [x] **10 Interactive 3D Procedural Models (`Phase 01`)**: Eukaryotic Cell, Prokaryotic Cell, T4 Bacteriophage, SARS-CoV-2, HIV-1, Influenza A, Ebola Virus, Zika Virus, Rabies Virus, and Measles Virus.
- [x] **10 Guided Narrative Tours (`Phase 01`)**: 44 chapters, 151 steps, and 655 unique / 767 total timed subtitle cues with `[[label|part]]` interactive 3D mesh highlighting.
- [x] **Effect-TS v4 Core Services (`Phase 01`)**: Type-safe `I18nService`, `SimulationState`, `CameraService`, `TourService`, and `AudioService`.
- [x] **100% Bilingual Localization (`EN` / `ES`) (`Phase 02`)**: Complete Spanish dictionaries in `es_nodes.ts`, `es_tours.ts`, and `es_phrases.ts` verified by automated unit and headless Chrome WebGL E2E checks (`tests/verify_all.ts`).
- [x] **GPT-SoVITS Voice-Cloned Pre-Generated `.opus` Tour Narration (`Phase 03`)**: Offline pipeline (`make export-cues && make generate-narration`) conditioning **GPT-SoVITS (`s1v3` + `v2ProPlus`)** on deep human studio/Mozilla Common Voice reference voices and serving `1,534` (`767 EN + 767 ES`) static `.opus` streams with next-cue prefetching.
- [x] **Optional User Accounts, In-Memory/Cookie Auto-Renewal & Per-Organism Course Resume + Reset (`Phase 04`)**: Lightweight Node.js 22 backend (`src/server/auth_progress_server.ts`) + client `CourseProgressManager` (`src/core/progress_service.ts`) + **`↺ Reset` (`#tReset` / Start from beginning)** button verified end-to-end in `tests/verify_all.ts`.
- [x] **Multi-Mode Explanation Lenses, Connected Supply-Chain Stories & Public-Domain Multi-Voice Narration (`Phase 05`)**: Hot-swappable `Simple`, `Story` (default), `Blueprint`, and `Scientific` reading lenses in `EN` and `ES` across all `208` Explorer nodes and `149` realistic 3D structures (`src/content/`), plus `7,995` pre-generated `.opus` clips across `3` English Public-Domain voices (`v1` Scientific, `v2` Blueprint, `v3` Simple/Story) and `2` Spanish Public-Domain studio voices (`latam` & `spain`) with automatic Preset switching and custom voice lock.
- [x] **Adaptive Narrator Personas, Multi-Script Guided Tours & Purposeful Analogies (`Phase 06`)**: Bidirectional Narrator ↔ Content Persona switching (`Molecular Biologist` → `Scientific`, `Systems Engineer` → `Blueprint`, `Everyday Guide` → `Story`/`Simple` with optional custom voice lock), `3` bespoke bilingual scripts (`pop`, `blueprint`, `scientific`) across all `10` Guided Tours (`4,602` cues), and sparse, purposeful analogies (`28` complex-mechanism tour cues, ~1 every 2 minutes, with clean direct prose everywhere else) across `8,762` pre-generated `.opus` narration clips in `15` `< 48 MB` archives.
- [x] **`0 · Introduction to Biology` 3D Stage & Reclassified Sequential Curriculum Tree (`Phase 07`)**: Comparative 4-pedestal WebGL2 primer stage (`life-overview`) with visual 4-Pillar Autonomy badges (`Membrane · DNA · Ribosomes · Own ATP`), 5-chapter multi-persona Primer Tour (`32` cues, `2` purposeful analogies), hierarchical `Stage 0 → 4` `#tree` starting cellular deep dives with Prokaryotes (*E. coli*), `Next in Course →` progression, and dedicated `< 48 MB` Stage 0 `.opus` shards (`8,994` total `.opus` clips).
- [x] **`3 · Parasitic & Minimal Cells` Realistic 3D Models & Tours (`Phase 08`)**: Standalone realistic WebGL2 scenes, Explorer node subtrees (`12` new nodes, `56` hover parts), 4-mode lenses, 3-persona Guided Tours (`135` cues across `3` tours with strict `2–3` complex-mechanism analogies per tour), and sharded `< 48 MB` GPU `.opus` audio (`audio_stage3_en.tar.gz`, `audio_stage3_es.tar.gz`; `10,044` total `.opus` clips) for *Mycoplasma genitalium* (minimal wall-less cell), *Chlamydia trachomatis* (Elementary/Reticulate cycle + `Npt1` ATP theft inside an inclusion), and *Rickettsia prowazekii* (cytosolic ATP parasitism, actin comet tails & evolutionary link to mitochondria).
